# Historical TIDE-0.5 reference

The [source archive](quellen-0.5.tar.xz) contains the earlier Python interpreter, its terminal and documentation hosts, the four integration test files, and the package metadata at that time. During archiving, files were compared byte-for-byte with the originals after extraction, including the targets of both symbolic links. Generated bytecode caches were omitted. The SHA-256 checksum of the archive is `565957d974d5a2b5d146ac4ffbca823692b61699f391095e30588987078e6ae3`.

To read an old comparison, the project repository at that time can be unpacked into a temporary directory. The historical link `apps` points there as before to the selected application sources.

```sh
stand=$(mktemp -d)
mkdir -p "$stand/experimente/referenzsystem"
ln -s "$PWD/apps" "$stand/apps"
tar -xJf experimente/referenzsystem/quellen-0.5.tar.xz -C "$stand/experimente/referenzsystem"
```

The current entry point is `./tide` in the project repository. `make test` builds the tests from TIDE sources, `make check-no-python` checks the complete rebuild and the installed package. [Build and installation](../../README.md#installation-and-verification)
