# Native check of type declarations

First, secure the results of the previous public command with the same filename and exactly the same bytes as comparison. Then execute the same call with the installed native package in an environment without Python, reference starter, and project modules. The complete JSON results, exit status, the empty output on the other channel, and the revision hashes must match.

The corpus includes new records and variants, types from Nano and Space Invaders, forward references, split subtrees, cycles, unknown types, valid and invalid bindings, pairs, deep type expressions, and record chains at both boundaries. It includes blank lines, CRLF, Unicode whitespace, same-named tags of different variants, and errors with source positions. Divergent lock files and unported programs must either pass the existing reference check or explicitly terminate as unsupported in the pure installation.

For small valid and invalid files and a larger type union, use three warm-up pairs and 20 measurement pairs in varying order. For the installed tool, measure the total time from process start to the checked response. Measure the overhead for a fallback in a program with functions separately against the reference starter. Model time and tokens are not collected in this experiment.
