# Native heating degree hours

The program sums the positive differences to the base temperature 18 for 16 hours. The target value is 39. Upon falling below, it first checks the subtraction and then the addition for i64 overflow. An hour starting from 18 contributes nothing. The data is fixed for both programs.

- Before measurement, compare the unchanged balance binary code against the previous compiler and check the native returns or overflow codes of all programs from `faelle.tide` against their target value and the TIDE reference. The test case list covers branched integer and boolean expressions, switching boolean operations, limits, the position variable starting from one, and nested intermediate results.
- Measure on a fixed logical CPU under Linux x86-64. The normal native program and a CPython script with the same i64 checks must each output 39. Measure process start, calculation, output, and end over 30 pairs after six warm-up pairs. The language with the first start switches.
- For repeated runs 32,768 and 131.072, measure complete evaluations per process. The TIDE measurement call `compile_repeated` nests a repetition around the invocation of the normal compute core. The core's machine bytes and input data must be identical in all three ELF files. Python repeatedly calls the same function with the same data. Both processes output the last value once. Over 24 rounds, use all 24 orderings of the four instructions after four warm-up rounds. The time difference long minus short, divided by 98.304, estimates the time per complete evaluation in the running process. Negative differences are reported.
- Measure the build time of the normal native program from source separately in ten runs after two warm-up runs. It includes source validation, compiler run, transfer of generated bytes, and setting the execution bit. Model tokens and repair time are not measured here.
