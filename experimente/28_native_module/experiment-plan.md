# Native Module Resolution

The public commands check, fmt, and test are compared at the same path with the same project. For check, complete JSON, module order, and revision hash are counted. For fmt, the exact text of the entry file is counted. For errors, exit status, error code, additional fields, and source position are counted. Execute the installed native command in a mount namespace without Python and without the reference starter.

Check cases include chains, diamonds, duplicate imports, module and type cycles, missing modules, file type, UTF-8, faulty use lines, the limits of depth, module count, and source bytes, as well as an error in another file. A change only in the leaf of a diamond must change the revision. An unported function body must not yield a successful check.

For single file, diamond, error in imported file, and broad bundle after three warm-up pairs, measure 20 paired complete check calls in alternating order. Reference is the direct previous reference starter with identical inputs. No new model measurement runs.
