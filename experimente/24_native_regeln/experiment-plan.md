# Native state rules

Translate heat, pump, and light unchanged via the ordinary entry point and via the parameterized simulation. The reference must pre-check the same source. For each application, check the existing examples and at least 100 different deterministic event sequences on the same executable file. The correctness metric is the complete output list, error code, and exit status.

Further rules check multiple state fields, swapped action order, start values, the first matching branch, division, overflow, missing partial output, and the event number in case of an error. The event limit of 4,096 and the work limit of 100,000 steps must work as in the reference. The existing calculation programs retain their binary hashes.

For a rule with integer events and one with boolean events, measure six warm-up pairs and 30 temporally paired process calls per size (16 and 4,096 events). CPython receives identical decimal or boolean arguments and the same output obligation. Input sequences alternate between pairs, and language order alternates. Result verification occurs outside measurement time. Record build time separately.

After the first correct run, a separate pair comparison follows between the continuously counted version and a statically bounded version. Both files process the same 4,096 events. Per rule, 40 pairs after eight warm-up pairs with alternating start order. Report file size and time gain separately. The demanding budget rule must continue to abort at the exact same event.
