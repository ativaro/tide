# Build the native compiler without Python

`make native` produces `build/native/tidec`. `./tide build QUELLE AUSGABE [EINSTIEG]` uses this file for the normal native build. The backend writes the Linux-x86-64 instructions and ELF segments itself. The finished application contains neither the bootstrap runtime nor a C++ library.

The first build on Linux x86-64 requires GNU Make, a C++20 compiler with static C++ and C runtime libraries, binutils, xz, xxd, and the usual Unix file tools. For the project checker and AOT, development headers from libcurl and libpq are added. A built HTTPS client loads libcurl, a PostgreSQL client libpq. The HTTP service is linked against libmicrohttpd. The archive contains a statically linked start compiler. Make checks its SHA-256 value before unpacking. This start compiler translates the combined modules `syntax.tide` and `seed.tide` into a temporary C++ translation unit. The system compiler generates a new start compiler from this. This start compiler translates itself again so that the compiler itself also uses the current Unicode runtime. From this, the seven TIDE modules of the ELF compiler are translated. A new build is possible with the delivered start image and the TIDE sources. During the one-time transition from the former reference system, its parser and interpreter were used. [Compiler sources](seed.tide) · [Build rules](../../Makefile)

`make check-native` lets two consecutive generations translate the same compiler source code and compares both target code and native files byte-for-byte. Subsequently, the bootstrap tests written in TIDE run. The start image is a trust anchor. Hash and self-build check consistency; its origin cannot be proven from this alone. [Compiler tests](compiler_checks.tide) · [Program tests](checks.tide) · [Archive checksum](seed.sha256)

The internal start compiler variant `main@compiler` processes up to 1 MiB of merged tool sources. It reads full lines in groups, so translation units with more than 4,096 lines are also processed. For individual TIDE lists, the limit is 4,096 elements. At the public project entry, the limit is 128 KiB.

For contract fingerprints, the start compiler translates bitwise AND and XOR on i64 values and the right rotation of the lower 32 bits. The rotation width counts modulo 32, and the result lies between 0 and 4.294.967.295. These three private operations are used by the SHA-256 module for contract and revision checks. [Measurement at public project entry](../../experimente/37_vertragsfingerabdruecke/report.md)

The start compiler is an internal tool for known compiler and check sources. It translates functions, lists, options, nested pairs, records, and closed variants. At `match`, each variant receives its own target type. The native build returns missing, unknown, and duplicate cases. `make test` runs, among other things, the unchanged application sources of Nano and Space Invaders with TIDE check functions. The build assembles their known modules. The tool execution decodes UTF-8 on read and uses code points for text positions. [Editor check](../../apps/nano_checks.tide) · [Game check](../../apps/invaders_checks.tide)

`make check-https` checks HTTPS page fetch, timeout, certificate, and rollback with a local TLS server. `make check-postgres` checks the service including a real HTTPS POST and a running locked SQL query with a temporary PostgreSQL cluster. The cluster is set up by the unprivileged user who starts the test.

## Check in an isolated environment

`make check-no-python` repeats the new build on Linux x86-64 in Debian. The build receives the product sources and the checked start compiler. The test searches for the Python interpreter, standard library, and runtime library, builds the tools, checks their static binding, and compares an updated old installation with a new installation. Afterwards, a custom runtime image executes the installed commands without Make and C++ compilers. An intentionally faulty balance program is diagnosed, corrected, and compared against the original there. [Container check](no-python.Dockerfile)

The clean rebuild occurred on 17 November 2026 with GCC 16.2.1 in a dedicated Linux mount namespace and with an empty build directory. Under `/usr/bin`, only the required build programs were included. Neither a Python interpreter nor the reference starter or the module `tide_lang` were available in the working tree. The Python standard library and the shared Python runtime were hidden.

Twelve newly generated ELF files were byte-identical to the previous compiler path, each for the fixed and one parametrized entry of the six applications. All 45 catalog operations delivered byte-identical the previous output. [Test protocol and SHA-256 values](pruefung.json)

The native data checker under `tide check`, `fmt` and `test` processes type declarations from the entry file and their transitive imports. It checks field names, type expressions, named references, and the depth of the record graph. `check` forms the revision hash from the same snapshot. `fmt` checks the normalized version again. A valid pure type file yields at `test` zero executed examples. A project may contain a total of 128 KiB source code and 64 additional modules. The maximum import depth is 32 including the entry. The reader receives per module a snapshot of the UTF-8 file. Line processing also reads long lines piecewise. Internal lists are limited to 4,096 elements. [Project resolution](project_model.tide) · [Data checker](schema.tide) · [Differential check and measurement](../../experimente/28_native_module/report.md)

Ordinary catalog queries with `--project DATEI` check the next `tide.lock` natively. The three strings may be reordered. A deviating supported pin reports `E_VERSION`. The native pin checker reports for previously unported forms `E_BACKEND`. For functions with integers, truth values, texts, as well as lists and options of these values, `run`, `test`, `check` and `fmt` process the checked project state natively. The checker determines function signatures, call depth, and possible errors across module boundaries. The evaluator considers short-circuiting and consumed work even for reused results. Records and variants also run in typed lists, options, and record fields. Thus, the game states and image construction of Space Invaders can be executed via the public CLI. Also, composite pairs and named read permissions are natively available. Interactive terminal control is open. The function evaluator counts the actually evaluated expressions for each fold. `list` and `append` load the same guest memory budget across all function calls. Source tokens and expression nodes are stored in groups of 256 entries for wide list literals. [Checks up to 4,096 elements](../../experimente/30_native_listen/report.md)

Rules with scalar events and outputs use the same typed expression tree as functions. During the transition, the old and new states remain separate. Expressions, field actions, and events are charged to the caller's work budget. The trace stops at the requested event.
